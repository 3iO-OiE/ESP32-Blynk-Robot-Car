# ESP32-Blynk-Robot-Car
A WiFi-controlled robot car powered by ESP32 and the Blynk IoT platform. This project allows remote control of the robot using a mobile app with four directional buttons (Forward, Backward, Left, Right) and optional speed adjustment. Built for hobbyists, students, and robotics enthusiasts using the L298N motor driver

🧰 Features

Remote control of robot directions

PWM speed control for motors

Blynk IoT integration
